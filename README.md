
# HR Analytics Dashboard – Power BI

## 📌 Overview
This project analyzes employee attrition and key HR metrics using Power BI to help organizations understand workforce trends and retention issues.

## 📊 KPIs & Metrics
- Total Employees
- Attrition Count
- Attrition Rate
- Department-wise Attrition
- Gender-wise Attrition

## 🛠 Tools & Technologies
- Power BI
- DAX
- CSV Dataset

## 📈 DAX Measures Used
- Attrition Count
- Attrition Rate
- Total Employees

## 🔍 Key Insights
- Certain departments show higher attrition rates
- Attrition varies by gender and job role
- Attrition rate helps identify retention risk areas

## 🚀 How to Use
1. Download the `.pbix` file from the Dashboard folder
2. Open it in Power BI Desktop
3. Refresh data if required
